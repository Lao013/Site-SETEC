# SETEC 2026 - FATEC Sorocaba

Site desenvolvido para a **SETEC 2026 - Semana de Tecnologia da FATEC Sorocaba**, com o objetivo de apresentar a programação do evento, palestrantes, equipe, brindes e demais informações aos participantes.

## 📚 Sobre o projeto

A SETEC (Semana de Tecnologia) é um evento voltado para estudantes e profissionais da área de tecnologia, proporcionando palestras, minicursos, mesas-redondas e apresentações relacionadas ao mercado de trabalho e às diferentes áreas da Tecnologia da Informação.

Este projeto foi desenvolvido como parte das atividades acadêmicas da **FATEC Sorocaba**.

- CSS3
