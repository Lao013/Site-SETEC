# 💜 SETEC 2026 — FATEC Sorocaba

## 📚 Semana de Tecnologia — XXIII SETEC

Projeto desenvolvido para a **XXIII Semana de Tecnologia (SETEC) da FATEC Sorocaba**, com o objetivo de disponibilizar de forma organizada e acessível a programação do evento, informações sobre palestrantes, brindes, equipe e apoiadores.

O site foi desenvolvido como um projeto acadêmico, aplicando conceitos de desenvolvimento web, estruturação de páginas, estilização com CSS e organização de conteúdo.

---

## 🎯 Objetivo do Projeto

Criar uma página web para apresentar as informações da SETEC 2026 de maneira clara, organizada e visualmente atrativa.

O sistema permite consultar:

- 📅 Programação do evento
- 🗓️ Atividades organizadas por dia
- 🎤 Palestrantes
- 🎁 Brindes
- 👥 Equipe responsável
- 🤝 Apoiadores
- 🔗 Links e informações relacionadas ao evento

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido utilizando:

- **HTML5** — estrutura das páginas
- **CSS3** — estilização e responsividade
- **JavaScript** — funcionalidades e interações
- **Git** — controle de versão
- **GitHub** — hospedagem e colaboração do projeto

Também foram utilizados recursos externos, como fontes e ícones, quando necessários.
